# 儿童棉花睡袋棉服 · 裁剪与缝制图解

身高 115–125cm 男童的一片式连帽棉花睡袋棉服做法。一份纸样做两件，
包含成品预览、尺寸表、裁片图、排料图、绗缝图解和六步拼接图解。

打开 `index.html` 即可阅读，也可以直接看 `preview/` 里的图片。

## 内容

| 章节 | 说明 |
| --- | --- |
| 成品预览 | 连帽、胸前开扣、袖口与裤脚罗纹、方格绗缝的正面效果 |
| 尺寸 | 成品规格 + 每个部位裁多长（净尺寸，另加 1.5cm 缝份） |
| 裁片 | 前后身、袖子、裤腿、帽子、裆片、罗纹的尺寸标注图 |
| 排料 | 150cm 宽布面怎么摆，外层和里层各排一遍 |
| 绗缝 | 里布 + 棉花 + 外布三层怎么叠、方格绗缝怎么走 |
| 拼接 | 肩缝 → 上袖 → 侧缝 → 裆片 → 收口 → 前襟与连帽 |
| 洗护 | 30℃ 轻柔机洗、平铺阴干、禁高温烘干 |

## 核心参数

- 适合身高：115–125cm，偏瘦中等体型
- 胸围：84cm（净胸围约 64cm + 20cm 活动量）
- 全身净长：肩到脚口 126cm，连帽再加约 30cm
- 面料：纯棉针织（双面针织 / 罗马布，250–320g/㎡）
- 填充：新疆棉（皮棉），450–500g / 件
- 一件买料：纯棉针织 7m（外层 3.5m + 里层 3.5m）、新疆棉 450–500g、罗纹布 0.8m
- 两件合计：纯棉针织 14m、新疆棉 约 1kg、罗纹布 1.6m

## 本地运行与验证

页面是纯静态的单文件，直接双击 `index.html` 就能看，不需要构建。

```bash
npm test          # 尺寸与内容自检（19 项）
npm run validate  # 同上，打印逐项结果
```

浏览器渲染自检（用系统 Edge/Chrome 截图，验证无横向溢出、无空图）：

```bash
node tests/render.mjs
```

## 说明

页面里的图都是按标注尺寸绘制的示意，实际裁剪以量到的孩子尺寸为准。
棉花必须绗缝固定，否则机洗会跑棉，这一步不能省。
